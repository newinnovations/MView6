# Command Palette & Slideshow Mode

[Documentation index](README.md) · [Project README](../README.md)

The Command Palette helps you find actions quickly. Slideshow mode automatically moves through the files in the current folder or archive.

## Command Palette

Press `Ctrl + Shift + P` to open the Command Palette. Start typing what you want to do, use `Up` and `Down` to choose a result, then press `Enter`.

You can use it for actions such as:

* Showing or hiding the file list and information panel.
* Switching PDF page layout or PDF engine.
* Changing transparency background style.
* Rotating the view.
* Starting measurement or slideshow tools.

---

## Slideshow mode

Slideshow mode moves through the current folder or archive automatically.

Start or stop it from the Command Palette by searching for "Start slideshow" or "Stop slideshow". You can also use the main application menu, or the navigation pad.

You can choose how long each item stays on screen:

* 1 second
* 3 seconds, the default
* 5 seconds
* 10 seconds
* 30 seconds
* 60 seconds

When the slideshow reaches the last item, it continues again from the first item.
